# Banco de Dados

Repositório didático do componente **Banco de Dados (60h)** da Qualificação Profissional em Desenvolvimento Web Back-End.

## Projeto integrador

O curso é conduzido pela construção incremental de um **Sistema de Gestão Escolar**, começando pela análise do domínio e SQL e avançando para Vanilla JavaScript, Node.js, Sequelize e uma comparação orientada com Prisma.

## Tecnologias

- MySQL Community e MySQL Workbench;
- SQL com preferência por construções ANSI;
- HTML, CSS e Vanilla JavaScript;
- Node.js e Express;
- Sequelize como ORM principal;
- Prisma para laboratório comparativo;
- Git e GitHub.
