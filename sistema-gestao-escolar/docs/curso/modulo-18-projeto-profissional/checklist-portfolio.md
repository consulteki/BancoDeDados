# Checklist de portfólio

## Repositório

- [ ] nome e descrição claros;
- [ ] README com arquitetura e comandos;
- [ ] licença definida;
- [ ] commits compreensíveis;
- [ ] issues ou backlog;
- [ ] nenhum segredo ou dado real.

## Engenharia

- [ ] migrations reversíveis;
- [ ] seed fictício;
- [ ] constraints relevantes;
- [ ] transação de matrícula;
- [ ] índices justificados;
- [ ] testes repetíveis;
- [ ] CI ativa;
- [ ] Docker saudável;
- [ ] OpenAPI validado;
- [ ] backup restaurado.

## Comunicação

- [ ] diagrama legível;
- [ ] screenshots sem dados pessoais;
- [ ] decisão Sequelize × Prisma;
- [ ] ADR de decisão relevante;
- [ ] limitações explícitas;
- [ ] roadmap priorizado;
- [ ] roteiro de demonstração ensaiado.

## Revisão final

- [ ] uma pessoa externa seguiu a instalação;
- [ ] erros encontrados foram registrados;
- [ ] evidências possuem data e ambiente;
- [ ] links internos funcionam;
- [ ] versão final possui tag.
